# Finance AI OS v2.5 architecture

```text
                     CFO / Finance Team
                            |
                  OpenClaw / Hermes Agent
                            |
                      Finance MCP :8090
                            |
                       READ-ONLY tools
                            |
                      Finance Core :8088
                            |
                 deterministic finance logic
                            |
                     Odoo 19 connector
                            |
             customers / invoices / residuals
                            |
                         Odoo 19
```

## Control boundary
The agent never receives direct database credentials and never calls Odoo write methods. Finance MCP exposes analytical tools only. Odoo writes in this repository exist only in the explicit **demo seed** and **web-user repair** administration scripts, which must not be run as agent tools.

## Source model
- Facts: Odoo posted customer invoices and residual balances.
- Calculations: AR, DSO, aging, concentration and risk buckets in Finance Core.
- Inferences: explanations generated by agent runtimes from MCP results.
- Recommendations: require human approval.

## Odoo 19 API note
The current pilot connector retains XML-RPC because the deployed CUSTOMER #001 stack already authenticates through it. Odoo 19 marks XML-RPC/JSON-RPC as deprecated and schedules removal in Odoo 22. The long-term adapter should move to JSON-2 and API-key authentication.
