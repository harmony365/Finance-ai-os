# Hermes integration

1. Put `finance-mcp` and `hermes` on the same Docker network (`scripts/connect-runtimes.sh`).
2. Merge `config.yaml` into the Hermes MCP configuration.
3. Apply `SYSTEM.md` as the finance-agent system policy.
4. Keep the tool allowlist exactly as provided during SHADOW mode.
5. Validate with: “Analiza el riesgo de caja y explica los drivers del DSO usando solo Finance AI OS.”
